# 📈 Real-Time Stock Market Dashboard

A Python-based stock market dashboard that fetches stock market data through an API and visualizes price movements, trading volume, and technical indicators using Streamlit and Plotly.

## 🚀 Features

- 📊 Stock price visualization
- 🕯️ Candlestick chart
- 📈 SMA 20 (20-day Simple Moving Average)
- 📈 SMA 50 (50-day Simple Moving Average)
- 📉 EMA 20 (20-day Exponential Moving Average)
- 📊 RSI (Relative Strength Index)
- 📉 MACD and Signal Line
- 📦 Trading volume visualization
- 💰 Current stock price
- 📈 Daily percentage change
- 🔄 Refresh stock data
- 📋 View raw stock data
- 🎛️ Select different stocks
- 🌙 Dark-themed interactive charts

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly
- Requests
- Streamlit
- python-dotenv
- Alpha Vantage API
